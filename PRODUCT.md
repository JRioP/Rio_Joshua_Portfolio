# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Tech recruiters, hiring managers, engineering leads, and clients evaluating full-stack and mobile capabilities for full-time roles, contracts, or engineering team additions. They need to quickly assess technical competence, code quality, UI craft, and project depth within seconds.

## Product Purpose
To showcase Joshua Rio's capabilities as a pragmatic product builder who ships production-ready end-to-end applications across web, mobile, and AI. Success means converting visitors into interview invitations, direct outreach, and high-impact engineering collaborations.

## Positioning
A pragmatic product builder focused on shipping production-ready end-to-end applications. Bridges native Android development (Java/Kotlin), modern Next.js/React web platforms, and practical AI integrations into tangible, deployable software.

## Operating Context
Evaluated primarily on desktop browsers (during recruiter desk reviews) and mobile devices (quick link reviews via LinkedIn/resume). Visitors scan hero credentials, inspect interactive case studies, test the integrated AI chat assistant, and download or view the resume.

## Capabilities and Constraints
- Production Next.js 16 App Router application with Turbopack, TypeScript, Tailwind CSS v4, and React 19.
- Live AI chat assistant powered by Google Gemini API (`/api/chat`).
- Interactive project case studies with screenshots, tech stacks, and live/source code links.
- Interactive contact form (`/api/contact`) with validation and responsive state feedback.
- Dark mode and custom Light mode theming.
- Fast page load performance, responsive mobile layout (min 44px touch targets), and accessible navigation.

## Brand Commitments
- Identity: Joshua Rio (@JRioP), Batangas, Philippines.
- Voice: Pragmatic, confident, approachable, and craft-conscious. Emphasizes tangible outcomes, real stacks, and shipped software.
- Typography: Display headings in `Gibed` (`--font-display`), body in `Plus Jakarta Sans` (`--font-sans`), technical details and code in `DM Mono` (`--font-mono`).
- Palette: Light mode utilizes Lake Blue (`#6D8EC5`), Flame (`#D3622C`), and Saffron (`#F0C845`) over crisp canvas `#F4F7FC`/`#FFFFFF`. Dark mode utilizes deep midnight neutrals (`#0a0a0a`/`#171717`) with electric blue (`#3b82f6`) accents.
- Tech Stack Logos: Authentic brand colors preserved across all SVG icons.

## Evidence on Hand
- Real project implementations and case studies: DentaVault, Mayo Holdings, Portfolio Website, Android applications.
- Real certificates and credentials in `public/images/cert/`.
- Verified GitHub repository and social links (`https://github.com/JRioP`, LinkedIn).
- Live Gemini API chat integration demonstrating full-stack API and prompt engineering skills.

## Product Principles
1. **Show, Don't Just Tell**: Prioritize working demos, live links, clear architecture breakdowns, and authentic metrics over generic claims.
2. **Immediate Clarity**: Visitors should understand who Joshua is, what he builds, and how to reach him within the first 5 seconds.
3. **Respect the Visitor's Time**: Fast navigation, scan-friendly typography, low friction to inspect case studies or grab the resume.
4. **Pragmatic Craftsmanship**: Clean code, production-grade responsiveness, high visual appeal, and zero broken states across themes and screen sizes.

## Accessibility & Inclusion
- High color contrast meeting WCAG AA standards in both light and dark themes.
- Touch targets $\ge 44\times 44\text{px}$ on mobile screens.
- Screen-reader friendly semantic HTML tags and ARIA labels on interactive elements.
- Explicit cookie consent controls respecting user analytics privacy.
